# nonebot2-ban-cmd

> 「禁言我以执行指令，26 秒为帮助。」——践踏用户交互体验的极致实验。

## 简介

本项目是一个基于 NoneBot2 + OneBot V11 的反人类交互 Bot 示例。

摒弃了传统的消息触发与指令匹配，本项目采用**给 Bot 禁言指定时长**作为唯一指令输入方式。

## 交互哲学

1. **天然物理前摇**：因为 Bot 在群内被禁言期间无法发送消息，因此任何指令的响应时间**严格大于等于禁言时长**。例如执行帮助指令（26 秒），需等待 27 秒前摇结束。
2. **绝对特权门槛**：普通群员无法使用任何指令，必须拥有管理员或群主身份对 Bot 施加禁言。
3. **风控共存亡**：高频执行指令可能导致群管理和 Bot 共同触发腾讯风控。

## 指令映射

| 禁言时长 | 指令名称 | 响应延时 | 说明 |
| :--- | :--- | :--- | :--- |
| **26 秒** | 获取帮助 | ~27 秒 | 打印帮助菜单 |
| **60 秒** | 摸鱼问候 | ~61 秒 | 摸鱼问候语 |
| **120 秒** | 系统状态 | ~121 秒 | 查看被践踏至地心的系统体验状态 |

## 快速开始

### 依赖安装

```bash
pip install -r requirements.txt
# 或者使用 pdm / poetry / uv
```

### 运行

```bash
python bot.py
```
